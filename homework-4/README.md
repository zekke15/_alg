## 三、第一題：以迭代法求 √3

原始方程式：`x² - 3 = 0`，我們取正根 √3 ≈ `1.73205080757`，從初始值 `x₀ = 1` 開始。

### 三種公式

- **f1：固定點公式**：`x_(k+1) = 3/x_k`。以 x₀=1 起算，1、3、1、3… 永遠震盪，**不收斂**。
- **f2：鬆弛型更新**：`x_(k+1) = x_k - (x_k²-3)/4`。初始值 1 時逐步逼近正根。
- **f3：牛頓法**：`x_(k+1) = (x_k + 3/x_k)/2`。由牛頓法 `x - f(x)/f'(x)` 化簡而來，靠近非零根時通常呈二次收斂。

執行：

```bat
py iterative.py
py iterative.py --initial 1 --iterations 10
```

**前 4 次迭代的參考結果**（四捨五入）：

| k | f1 | f2 | f3 |
|---|---:|---:|---:|
| 1 | 3.000000 | 1.500000 | 2.000000 |
| 2 | 1.000000 | 1.687500 | 1.750000 |
| 3 | 3.000000 | 1.725586 | 1.732143 |
| 4 | 1.000000 | 約 1.731172 | 1.732051 |

**誤差計算**：`absolute_error = abs(x_k - sqrt(3))`。

**收斂判斷**：對固定點更新 `x_(k+1)=g(x_k)`，在根附近若 `|g'(x*)|<1` 通常局部收斂；若 `|g'(x*)|>1` 則局部發散，等於 1 時不能僅據此判斷。f1 在正根處導數為 -1，從 x₀=1 出現二週期震盪。f2 在根處導數 `1 - sqrt(3)/2 ≈ 0.134`，f3 在正根處導數為 0，因而 f3 通常收斂較快。

## 四、第二題：通用迭代框架說明

`generic_iterator(transition_func, is_finished, initial_state, max_iter=1000)` 將所有迭代方法統整成「**初始狀態 → 更新狀態 → 判定停止 → 重複**」。

- `transition_func(state)`：輸入目前狀態並回傳下一個狀態。
- `is_finished(old, new, iteration)`：判斷是否達到指定的停止條件。對求根可判定誤差，對 RK4 則可判定是否抵達時間終點。
- `initial_state`：初值，可為數字、向量、矩陣或 tuple。
- `max_iter`：最大迭代次數，避免永無止境的運算。

回傳 `(result, count, finished)`，依次表示最終狀態、執行步數、是否達到停止條件。框架另檢查 NaN/無限值，以便及早發現數值問題。

### 九種示範與原理

| 編號 | 演算法 | 核心狀態更新 | 用途／終止標準 |
|---|---|---|---|
| 1 | 二維固定點 | `X_(k+1) = g(X_k)` | 解非線性不動點，檢查前後向量距離 |
| 2 | 牛頓法 | `x_(k+1)=x_k-f(x_k)/f'(x_k)` | 求 `x²-4=0`，檢查步長及殘差 |
| 3 | Gauss–Seidel | 用最新可得分量依序解 `Ax=b` | 求線性方程組，檢查更新量與 `||Ax-b||` |
| 4 | Power Iteration | `v_(k+1)=Av_k/||Av_k||` | 找絕對值最大的特徵值／向量，檢查特徵殘差 |
| 5 | QR Algorithm | `A_k=Q_kR_k`，`A_(k+1)=R_kQ_k` | 估計對稱矩陣各特徵值，檢查非對角元素 |
| 6 | RK4 | 以四組斜率的加權平均更新 `(t,y)` | 數值積分 ODE，到達指定 `t=2` 終止（不是收斂判斷） |
| 7 | PageRank | `r_(k+1)=G r_k` | 估計網頁的重要程度，檢查分布差異 |
| 8 | K-Means | 分配最近中心，再重算群中心 | 資料分群，檢查群中心變動；保護空群 |
| 9 | EM 雙硬幣 | E 步估計歸屬權重，M 步更新參數 | 估計隱藏模型參數，檢查前後參數差異 |

### 為什麼能用同一框架？

這些演算法的實際更新方式不同，但都能把計算過程寫成 `state_(k+1) = transition(state_k)`。框架掌管重複執行與停止判斷，各演算法僅提供自己的轉移函式與判定條件，因此可以減少重複程式碼並方便測試。

### 補充注意事項

1. **不是所有迭代都能收斂**：結果依公式、初值、矩陣條件而異。
2. **Power Iteration** 一般收斂到絕對值最大的特徵值；用 Rayleigh 商計算對應估計值，需注意重根、同模特徵值等情況。
3. **QR** 這裡是基本未位移 QR，適用於本示範對稱矩陣，不是所有矩陣都同樣可靠。
4. **RK4** 固定步長往前積分，停止於指定時間，不代表誤差已小於某個收斂門檻。
5. **EM** 不保證求得全域最佳估計；對大樣本要注意計算極小機率時的數值穩定性。

## 五、演算法複雜度簡介

假設迭代次數為 K，狀態維度為 n，資料點數為 N，分群數為 c，特徵維度為 d；具體常數與向量化實作會影響實際效能。

| 演算法 | 典型時間（基本實作） | 額外空間（不計輸入） |
|---|---|---|
| 固定點（二維例） | O(K) | O(1) |
| 牛頓法（純量） | O(K) | O(1) |
| Gauss–Seidel（稠密 n×n） | O(Kn²) | O(n) |
| Power Iteration（稠密矩陣） | O(Kn²) | O(n) |
| 基本 QR（稠密矩陣） | O(Kn³) | O(n²) |
| RK4（純量 ODE） | O(K) | O(1) |
| PageRank（稠密矩陣） | O(Kn²) | O(n) |
| K-Means（N 筆、c 群、d 維） | O(KNcd) | O(Nc + cd) |
| EM 雙硬幣（N 組試驗） | O(KN) | O(1)（逐筆加總版本） |

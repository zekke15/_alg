# 遞迴關係式四題：精確公式與 Big O

## 作業目標
解出四個遞迴關係式的精確值，並分析漸近時間複雜度（Big O）。用 Python 遞迴函數驗證結果。

## 第一題：T(n) = T(n−1) + 8，T(1) = 1

展開：

```text
T(n) = T(n−1)+8
     = T(n−2)+8+8
     = T(1)+8(n−1)
     = 1+8(n−1) = 8n−7
```

**精確公式：** `T(n) = 8n − 7`  
**Big O：** `O(n)`。

## 第二題：T(n) = 2T(n−1) + 9，T(1) = 1

展開：

```text
T(n) = 2T(n−1)+9
     = 4T(n−2)+2×9+9
     = 2^(n−1)T(1) + 9(2^(n−1)−1)
     = 10×2^(n−1) − 9
```

**精確公式：** `T(n) = 10×2^(n−1) − 9`  
**Big O：** `O(2^n)`。

## 第三題：T(n) = 2T(n/2) + 1，T(1) = 1

**假設 n = 2^k**，則展開 k 層：

```text
T(n) = 2T(n/2)+1
     = 4T(n/4)+3
     = 2^k T(n/2^k)+(2^k−1)
     = nT(1)+(n−1) = 2n−1
```

**精確公式：** `T(n) = 2n − 1`  
**Big O：** `O(n)`。

## 第四題：T(n) = T(n/2) + 1，T(1) = 1

**假設 n = 2^k**，則展開 k 層：

```text
T(n) = T(n/2)+1
     = T(n/4)+2
     = T(n/2^k)+k
     = T(1)+log2(n)
     = 1+log2(n)
```

**精確公式：** `T(n) = log₂(n) + 1`  
**Big O：** `O(log n)`。

> 第三、四題若 n 不是 2 的整數次方，需另外定義 n/2 的取整方式，才能談精確的整數運算值。本作業為忠實對應題目，程式僅接受 2 的次方。

## 答案總表

| 題目 | 精確公式 | Big O |
|---|---|---|
| 1 | `8n−7` | `O(n)` |
| 2 | `10×2^(n−1)−9` | `O(2^n)` |
| 3 | `2n−1` | `O(n)` |
| 4 | `log₂(n)+1` | `O(log n)` |

## 說明

Big O 表示函數成長率的漸近上界，不是執行秒數；在此四題中也可用 Θ 表示緊確的漸近階。直接遞迴的 Python 實作是為了驗證數列，不能把數列值 T(n) 自動當成此 Python 程式本身的執行時間。

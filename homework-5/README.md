## 第一題：河內塔

三根柱子 A、B、C，起初 A 放著 n 個由大到小堆疊的圓盤。每次只能移動一個圓盤，大盤不可放在小盤上；目標是將全部圓盤搬到 C。

### A. 遞迴解法

`hanoi_recursive(n)` 的概念：

1. 將上面 `n-1` 個圓盤從 A 搬到 B。
2. 將最大的第 `n` 個圓盤從 A 搬到 C。
3. 將 B 的 `n-1` 個圓盤搬到 C。

每一次搬動上面 `n-1` 個圓盤，又可以拆成相同的小問題。當 `n=0` 時停止。

### B. 禁止遞迴解法

`hanoi_iterative(n)` **完全沒有呼叫自己**，改以 `stack`（堆疊）儲存「待解決」及「直接移動」兩類指令，並透過 `while` 取出指令。堆疊採後進先出，所以會反向放入三個工作，使執行順序與遞迴版相同。

### 例子：n=3

```text
1. 圓盤 1：A -> C
2. 圓盤 2：A -> B
3. 圓盤 1：C -> B
4. 圓盤 3：A -> C
5. 圓盤 1：B -> A
6. 圓盤 2：B -> C
7. 圓盤 1：A -> C
```

搬運次數公式為 `T(n) = 2*T(n-1)+1`、`T(0)=0`，因此共 `2**n - 1` 步。兩種版本時間複雜度都是 `O(2**n)`；遞迴使用呼叫堆疊，非遞迴使用自行管理的堆疊。

## 第二題：遞迴符號微分

### 觀念

`ast.parse` 將文字公式變成語法樹，`_differentiate` 遞迴走訪子節點，根據規則回傳新的語法樹，再用 `ast.unparse` 轉回數學式。程式 **不直接使用 `eval` 解析使用者輸入的公式**。

支援：數字、變數 `x`（其他名稱視為對 `x` 的常數）、`+`、`-`、`*`、`/`、`**`（指數須為數字常數）、單項正負號，另支援 `sin`、`cos`、`exp`、`log` 與鏈鎖律。以 `variable=` 可以指定微分變數。

主要微分規則：

| 規則 | 公式 |
| --- | --- |
| 常數 | `(c)' = 0` |
| 變數 | `(x)' = 1` |
| 加法 | `(f+g)' = f'+g'` |
| 乘法 | `(f*g)' = f'*g+f*g'` |
| 除法 | `(f/g)' = (f'*g-f*g')/g**2` |
| 常數次方 | `(f**n)' = n*f**(n-1)*f'` |
| 鏈鎖律 | `(sin(f))' = cos(f)*f'` |

例子：

```python
sym_diff("x**3 + 2*x + 5")  # 3 * x ** 2 + 2
sym_diff("(x+1)**3")       # 3 * (x + 1) ** 2
sym_diff("sin(x)")         # cos(x)
```

注意：Python 的次方符號是 `**`，**不是** `^`；`x**x` 這種變動指數尚未實作；目前只做局部簡化（如消除乘 0、乘 1），不保證把所有同類項合併。

## 第三題：自製 map/filter/reduce + 不使用迴圈的泡沫排序

### 自製函式

- `my_map(f, values)`：對每個值套用函式，回傳新清單。
- `my_filter(p, values)`：只保留使判斷為真之元素。
- `my_reduce(f, values, initial)`：從初始值累積計算結果。

三者都使用遞迴，不使用 Python 內建 `map`、`filter`，或 `functools.reduce`。

### 實際泡沫排序

`bubble_sort` 的步驟是：

1. 使用 `my_map` 複製資料，不改動原始清單。
2. `bubble_pass` 以 `my_reduce` 做一輪**相鄰比較**，將較大的值帶到右邊，最大值就會停在尾端。
3. `sort_prefix` 遞迴處理前面尚未排序的部分，取代外層迴圈。
4. 若某輪完全沒有交換，就提前結束。
5. `is_sorted` 透過 `my_filter` 尋找逆序相鄰配對，驗證結果。

範例：

```text
原始清單：[5, 1, 4, 2, 8, 2]
排序結果：[1, 2, 2, 4, 5, 8]
```

`functional_bubble.py` 完全沒有 `for`、`while`、列表推導式／集合推導式／字典推導式，也沒有使用 `sorted`。`test_homework.py` 的測試部分可以有迴圈，但不屬於第三題解題程式；測試會以 Python AST 檢查第三題的限制。

泡沫排序平均及最差時間複雜度為 `O(n**2)`，最好情況（已排序且提早結束）為 `O(n)`。自製高階函數以遞迴搭配索引實作，可避免逐次切片的額外成本；排序仍適合教學與小清單，清單過長時可能遇到 Python 遞迴深度限制。

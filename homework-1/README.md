# power2n.py：四種方法比較

老師要求計算 `2^n`，並比較直接計算、雙重遞迴、單次遞迴及遞迴搭配快取表。

## 執行
在 Windows CMD／VS Code 終端機輸入：

```bat
py power2n.py
```

不需要安裝其他套件。

## 複雜度

| 方法 | 時間複雜度 | 額外空間 |
|---|---|---|
| 直接 `2**n` | 大整數運算視模型與實作而定 | 結果占 O(n) 位元 |
| `f(n-1)+f(n-1)` | O(2^n) | O(n) 遞迴堆疊 |
| `2*f(n-1)` | O(n) 次遞迴呼叫 | O(n) 遞迴堆疊 |
| 遞迴 + 快取表 | O(n) 次狀態計算 | O(n) 項快取與 O(n) 堆疊 |

以上假設一般算術操作為固定成本；實際 Python 大整數運算會另外耗時。

## 為何不對雙重遞迴執行 n=100？

因為會重複計算兩個 `f(n-1)`，遞迴樹約有 `2^(n+1)-1` 次函數呼叫。
程式只對它測試 n=20，其餘方法測試 n=100。

計時採每輪 `perf_counter()`；一般方法重複 5 次並回報最快一次，雙重遞迴測試一次。不同電腦會有不同數值。

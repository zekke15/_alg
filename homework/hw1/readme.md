# 作業：布林可滿足性問題 (SAT) 真值表求解器

## 1. 問題描述
布林可滿足性問題（Boolean Satisfiability Problem, 簡稱 SAT）是計算機科學中第一個被證明為 NP-Complete 的決策問題。
本程式旨在針對合取範式（CNF）形式的布林邏輯公式，透過系統性列舉「真值表」（Truth Table）的窮舉方式，判斷該公式是否存在至少一組可滿足解（Satisfiable），若無解則判定為不可滿足（Unsatisfiable）。

---

## 2. 演算法設計與實作原理
若一個布林公式包含 $n$ 個布林變數，總共存在 $2^n$ 種可能的真假值組合。

1. **資料結構設計**：
   - 使用標準 DIMACS CNF 表示法。以整數代表文字（Literal）：正整數 $k$ 代表正文字 $x_k$，負整數 $-k$ 代表取反文字 $\neg x_k$。
   - 子句（Clause）由 OR（$\lor$）連接，整個公式由所有子句的 AND（$\land$）連接。
2. **真值表系統性窮舉**：
   - 利用 `itertools.product([False, True], repeat=n)` 按二進位計數順序系統性生成由 $00\dots0$ 至 $11\dots1$ 的所有指派組合。
3. **逐行評估公式**：
   - 子句計算：只要子句中有任意一個文字為真，該子句即為真。
   - 公式計算：公式中的所有子句必須全數為真，整個公式才算滿足。
4. **輸出結果與解的判定**：
   - 逐行打印完整真值表。
   - 若至少存在一行結果為 1，輸出 `SATISFIABLE` 並列出所有滿足條件的變數賦值；若所有可能均為 0，則輸出 `UNSATISFIABLE`。

演算法與函數式實作精選專案 (Algorithm & Functional Lab)本專案收錄三種常見電腦科學與函數式編程核心概念的純 Python 實作：河內塔問題的雙重解法、基於語法樹的符號微分器，以及純函數式無迴圈泡沫排序。目錄功能特性模組說明1. 河內塔問題 (Tower of Hanoi)2. 符號數學微分 (Symbolic Differentiation)3. 函數式無迴圈泡沫排序 (No-Loop Bubble Sort)快速開始模組測試與範例功能特性雙解法對照：對比經典遞迴與自建 LIFO 呼叫堆疊（非遞迴）模擬。抽象語法樹（AST）解析：支援基本四則運算與冪次連鎖律的符號微積分引擎。純函數式風格（Pure Functional）：自製 map、filter、reduce 原語，完全禁用 for / while 迴圈完成泡沫排序。模組說明1. 河內塔問題 (Tower of Hanoi)hanoi_recursive(n, src, aux, tgt)採用 Divide and Conquer 經典解法，時間複雜度為 $O(2^n)$。hanoi_iterative(n, src, aux, tgt)使用顯式堆疊模擬系統 Call Stack，支援狀態階段追蹤（Stage 0: 準備子問題, Stage 1: 輸出並處理後續），杜絕深度遞迴可能引發的呼叫堆疊溢位（Stack Overflow）。2. 符號數學微分 (Symbolic Differentiation)sym_diff(expr, var='x')運算式以巢狀 Tuple 表示（例如 ('+', ('^', 'x', 3), ('*', 4, 'x'))）。支援法則：常數法則：$\frac{d}{dx} c = 0$變數法則：$\frac{d}{dx} x = 1$線性法則：$(u \pm v)' = u' \pm v'$乘法萊布尼茲法則：$(uv)' = u'v + uv'$冪法則連鎖律：$(u^n)' = n u^{n-1} u'$3. 函數式無迴圈泡沫排序 (No-Loop Bubble Sort)原語實作：my_map、my_filter、my_reduce 均以尾端/遞迴拆解實作。排序流程：內層：single_bubble_run 透過 my_reduce 搭配累加器 Tuple (current_bubble, sorted_sublist)，在一次折疊中將最大元素推至陣列尾端。外層：以陣列長度構造虛擬步驟序列，經由外層 my_reduce 連續折疊執行 $n$ 次單趟推升。
